# 📊 Dataset Information

**Dataset:** `student_dataset.csv`

The dataset contains information related to student academic performance.

### 📋 Dataset Columns

| Column                | Description               |
| --------------------- | ------------------------- |
| Student_ID            | Unique Student ID         |
| Name                  | Student Name              |
| Gender                | Male/Female               |
| Age                   | Student Age               |
| Department            | Department Name           |
| Year                  | Academic Year             |
| Attendance            | Attendance Percentage     |
| Study_Hours           | Daily Study Hours         |
| Assignments_Completed | Assignments Submitted     |
| Internal_Marks        | Internal Exam Marks       |
| External_Marks        | External Exam Marks       |
| Total_Marks           | Total Marks               |
| Grade                 | Final Grade               |
| Sports                | Sports Participation      |
| Placement_Training    | Placement Training Status |
| Family_Income         | Family Income             |
| Internet_Access       | Internet Availability     |
| Scholarship           | Scholarship Status        |
| CGPA                  | Overall CGPA              |
| Result                | Pass / Fail               |
